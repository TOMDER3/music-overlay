# Music Overlay

Un overlay Spotify pour Windows, avec recherche, lecteur, file d’attente, titres likés et podcasts.

[Télécharger la dernière version](https://github.com/TOMDER3/music-overlay/releases/latest)

Téléchargez uniquement **MusicOverlay-Installer.exe**, puis lancez-le sans mode administrateur.
Spotify classique pour Windows doit être installé et ouvert. Chaque personne utilise son compte Spotify Premium et doit être autorisée par le créateur de l’application Spotify.

Dans l’overlay : **Paramètres → Connecter Spotify**.

- **Alt+S** : afficher ou masquer.
- **Échap** : masquer.
- **Alt+F5** : redémarrer l’overlay.
- **Alt+F6** : recharger Spicetify.

Mises à jour : **Paramètres → Rechercher les mises à jour → Télécharger → Installer et redémarrer**. La session et les réglages restent sur votre ordinateur.

Version de test Windows x64. Les licences des dépendances sont incluses dans le paquet.
